# Association of Tamil Canadian Community (ATCC) Website

## Overview

The official website for the Association of Tamil Canadian Community (ATCC), a non-profit organization dedicated to serving the Tamil community in Canada. This website serves as a digital hub for community members to stay informed about events, initiatives, and resources.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI/UX**: Clean and intuitive user interface with smooth animations
- **Multiple Pages**:
  - Home: Overview and highlights
  - About: Information about ATCC and its mission
  - Events: Upcoming community events and activities
  - Causes: Community initiatives and programs
  - Team: Meet the team behind ATCC
  - Donate: Support our community initiatives
  - Contact: Get in touch with us

## Technologies Used

- **Frontend**:
  - HTML5, CSS3, JavaScript
  - Bootstrap 5
  - Font Awesome Icons
  - jQuery
  - Owl Carousel
  - Animate.css
  - SASS (SCSS)

## Getting Started

### Prerequisites

- Web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code, Sublime Text, etc.)
- Node.js and npm (for development)

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd atccwebsite
   ```

2. Open `index.html` in your web browser to view the website locally.

## Development

### Folder Structure

```
atccwebsite/
├── css/              # Compiled CSS files
├── img/              # Image assets
├── js/               # JavaScript files
├── lib/              # Third-party libraries
├── scss/             # SASS source files
├── about.html        # About page
├── causes.html       # Causes/Initiatives page
├── contact.html      # Contact page
├── donate.html       # Donation page
├── events.html       # Events page
├── index.html        # Home page
├── team.html         # Team page
├── testimonial.html  # Testimonials page
└── README.md        # Project documentation
```

### Building from Source

1. Install dependencies:
   ```bash
   npm install
   ```

2. Compile SASS to CSS:
   ```bash
   npm run scss
   ```

3. Start the development server:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.
